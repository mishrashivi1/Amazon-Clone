🛒 Amazon Homepage Clone (HTML & CSS)

A static clone of the Amazon homepage built using HTML and CSS to practice layout design and styling.

🚀 Features

🧭 Navigation bar with logo, search bar, and menu
📦 Product sections layout
🎯 Banner / hero section
🧱 Grid-based product display
🎨 Styled using pure CSS

🧠 What I Learned

Structuring layouts using HTML
CSS Flexbox and Grid
Positioning elements properly
Building real-world UI layouts
Improving design accuracy by cloning

🛠️ Tech Stack

🌐 HTML
🎨 CSS (Flexbox + Grid)
